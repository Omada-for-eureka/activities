## Proposer ou organiser une activité

1. Ouvrir une [Issue « Proposer une activité »](https://github.com/Omada-for-eureka/activities/issues/new/choose) ou en parler dans `#propositions-activites`.
2. Créer la fiche depuis [templates/ACTIVITY_TEMPLATE.md](templates/ACTIVITY_TEMPLATE.md).
3. Après l'activité, publier le compte rendu depuis [templates/REPORT_TEMPLATE.md](templates/REPORT_TEMPLATE.md).

Parcours complet : [activity-workflow.md](https://github.com/Omada-for-eureka/community-handbook/blob/main/docs/activity-workflow.md).

## Organisation des fichiers

Chaque activité a son dossier, préfixé par sa date :

```text
workshops/
└── 2026-11-15-atelier-git-github/
    ├── README.md        (fiche de l'activité)
    ├── REPORT.md        (compte rendu)
    └── slides.pdf       (supports, si l'auteur les partage)
```
