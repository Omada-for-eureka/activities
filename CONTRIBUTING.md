# Contribuer aux activités

Règles générales : [community-handbook/CONTRIBUTING.md](https://github.com/Omada-for-eureka/community-handbook/blob/main/CONTRIBUTING.md).

## Avant l'activité

1. Ouvrir une Issue « Proposer une activité ».
2. Créer le dossier `<type>/AAAA-MM-JJ-nom-court/` et y copier [templates/ACTIVITY_TEMPLATE.md](templates/ACTIVITY_TEMPLATE.md) sous le nom `README.md`.
3. Ouvrir une Pull Request ; un responsable vérifie le calendrier et la logistique.

## Après l'activité

1. Ajouter `REPORT.md` depuis [templates/REPORT_TEMPLATE.md](templates/REPORT_TEMPLATE.md).
2. Ajouter les supports dont l'auteur autorise la publication.
3. Ne publier aucune liste nominative de participants : seulement le nombre.
4. Fermer l'Issue de l'activité.

## Challenges

Pour un challenge, ajouter dans le dossier :

- `README.md` : énoncé, règles, date limite.
- `solutions/` : solutions proposées par les participants (une par fichier, nommée par pseudo), après la date limite.
